# LiYaxuan C4B 教学说明

> 挑战：C4B 公众号文章生成技能
> 技能：`wechat-publisher`（基于 starter kit + skill-creator 定制，新增 5 项能力）

## 一、这个技能解决什么问题

写了一篇好文章，却要花半小时在公众号编辑器里手动调字号、调间距、调颜色？
本技能把 **Markdown → 公众号兼容 HTML** 做成一条命令：所有样式内联、无 class/id、
无禁用标签，**粘贴进 mp.weixin.qq.com 不丢格式**，还自带排版审美（5 套主题）与内容质检。

## 二、安装步骤

### 方式 A：安装 .skill 包（推荐给 AI 助手）

1. 将 `LiYaxuan_C4B_wechat-publisher.skill` 安装到你的 Agent 环境；
2. 对 AI 说"把这篇文章转成公众号格式"，AI 会自动调用本技能完成转换。

### 方式 B：命令行直接运行

```bash
# 1. 安装依赖
python -m pip install markdown beautifulsoup4 python-docx lxml

# 2. 转换（以"清新绿"主题 + 目录 + 元信息 + 页脚为例）
python scripts/convert_to_wechat.py 文章源文件.md output.html --theme green --toc --meta --footer

# 3. 发布三步曲
#    ① 浏览器打开 output.html 预览
#    ② Ctrl+A → Ctrl+C 复制
#    ③ 公众号后台新建图文 → Ctrl+V 粘贴 → 发布
```

## 三、比 starter kit 多了什么（5 项新能力）

| 新能力 | 用法 | 效果 |
|--------|------|------|
| ① 主题系统 | `--theme blue/orange/green/gray/purple` | 5 套配色，覆盖教程/活动/健康/职场/创意场景 |
| ② Callout 提示框 | 文章里写 `> [!note] 内容` | 生成 💡小贴士 / ✅实用技巧 / ⚠️注意 彩色提示框 |
| ③ 自动目录 | `--toc` | 文首生成编号章节目录（公众号兼容） |
| ④ 元信息栏 | `--meta` | 标题/作者/日期/字数/阅读时长 |
| ⑤ 内容密度检查 | 每次转换自动执行 | 段落≤120字、列表≤7项、代码块≤40行等质检报告 |

## 四、怎么写文章（内容规范）

1. 用 `##` 做章节标题（公众号顶级标题是 h2）；
2. 段落一句话一换行，≤120 中文字符（手机端可扫读）；
3. 列表 ≤7 项，超出拆小节；
4. 全文至少 3 个章节；
5. 关键提示用 callout，每 500 字不超过 1 个；
6. 引用别人内容用 `>` 引用块。

## 五、常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 粘贴后格式丢了？ | 检查源文件是否有禁用标签（div/script/style/class），转换器会自动清理，但清理后可能变形，建议先预览 |
| 目录点不动？ | 公众号不支持 id 锚点跳转，目录是"编号预览列表"，这是平台限制 |
| 想换主题色？ | 参考 `references/theme_palettes.md` 在 `THEMES` 字典加一组颜色 |
| 图片怎么处理？ | PNG base64 自包含最稳；照片上传公众号媒体库后用 CDN 链接 |
| 页脚二维码怎么换？ | 转换后 HTML 里有"（此处替换为你的公众号名片二维码）"占位，发布前用媒体库图片替换 |
| 没有公众号账号？ | 文章源文件 + output.html 本身就是交付物，注册账号后可一键粘贴发布 |

## 六、边界情况

- 未知主题名 → 报错并列出可用主题；
- 文章无 `##` 章节 → 密度检查提示"章节过少"；
- 输入 .html → 先净化再排版；
- 依赖缺失 → 脚本自动安装。
