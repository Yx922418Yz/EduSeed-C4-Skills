# WeChat Official Account HTML Restrictions（升级版）

公众号编辑器允许/禁止的标签、属性、CSS 完整参考。转换器必须强制这些规则，
否则粘贴后格式丢失。新增：**内容密度规则**（信息密度检查依据）。

## 允许的 HTML 标签

```
p, h2, h3, ul, ol, li, span, img, a, table, tr, th, td, br
```

## 禁止的 HTML 标签

| 标签 | 原因 | 处理 |
|------|------|------|
| `<h1>` | 公众号保留 h1 给文章标题 | 转为 `<h2>` |
| `<div>` | 渲染不可靠 | 转为 `<p>` 或 `<span>` |
| `<script>` | 安全 — 总是被剥离 | 直接删除 |
| `<style>` | 只允许内联 CSS | 移到 `style=""` 属性 |
| `<iframe>` | 禁止外部嵌入 | 删除或转链接 |
| `<video>` | 必须用公众号视频功能 | 删除或转链接 |
| `<audio>` | 必须用公众号音频功能 | 删除或转链接 |
| `<details>` | 折叠面板不支持 | 转普通列表 |

## 禁止的 HTML 属性

| 属性 | 原因 | 处理 |
|------|------|------|
| `class` | 公众号无 CSS 类 | 删除 |
| `id` | 不支持元素 id | 删除 |
| `onclick` 等 | 无 JS 事件 | 删除 |

## CSS 规则

### 必须内联
每个元素都要 `style="..."` 直接写在标签上。

### 允许的 CSS 属性
```
color, background-color, font-size, font-weight, font-style,
line-height, text-align, margin, padding, border, border-left,
border-collapse, text-decoration, border-radius
```

### 禁止的 CSS
- `position` / `float` / `flex` / `grid`（布局类）
- `animation` / `transition`（动效类）
- `@media` 媒体查询（无响应式断点）
- `@font-face` 自定义字体

## 图片规则

| 方式 | 可用? | 说明 |
|------|-------|------|
| `<img src="https://...">` | ⚠️ | URL 可访问时可用，公众号可能转存 |
| `<img src="data:image/png;base64,...">` | ✅ | 粘贴后自动转 CDN 托管 |
| `<img src="data:image/svg+xml;base64,...">` | ❌ | 保存后消失（公众号无法重传 SVG） |
| 内联 `<svg>` | ❌ | 完全剥离 |

**最佳实践**：自包含图片用 PNG base64；照片上传到公众号媒体库后用 CDN URL。

## 文章限制

| 限制项 | 数值 |
|--------|------|
| 最大文章长度 | ~20,000 中文字符 |
| 最大图片数 | 100 张/篇 |
| 单图最大 | 10 MB |
| 支持图片格式 | PNG / JPG / GIF |
| 最大 GIF | 2 MB |

## 信息密度规则（C4B 新增能力，--密度检查）

转换时自动执行 `lint_content()`，输出密度检查报告：

| 规则 | 阈值 | 违规提示示例 |
|------|------|--------------|
| 段落中文字符数 | ≤ 120 | 段落过长（156 中文字符 > 120） |
| 单个列表条目数 | ≤ 7 | 列表条目过多（12 > 7），建议拆分 |
| 单个 H2 下 H3 数 | ≤ 5 | 章节下子标题过多 |
| 文章 H2 章节数 | ≥ 3 | 章节过少，建议至少 3 个 H2 |
| 代码块行数 | ≤ 40 | 代码块过长，建议精简 |

> 手机端长段落极易跳读，密度规则保证文章"信息密度可控、一眼可扫"。

## 常见坑（沿用 starter + 新增）

1. **粘贴后格式丢失**：通常用了禁用标签或 CSS
2. **图片消失**：SVG data URI 或失效外链
3. **间距异常**：公众号折叠 margin 方式与浏览器不同
4. **代码块破碎**：必须用 `<p>` + inline style，不能用 `<pre><code>`
5. **表格过宽**：手机无横向滚动，宽表要拆列
6. **目录不跳转**：公众号无 id 锚点，目录用编号列表（文首定位）
7. **页脚二维码**：必须用公众号媒体库上传的图片，外链可能被防盗链
