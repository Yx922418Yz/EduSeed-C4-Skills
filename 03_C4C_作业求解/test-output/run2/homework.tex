\problem{5}

求微分方程 $y'' - 5y' + 6y = 0$ 的通解。

\solution

识别为 2 阶常微分方程：6 y{\left(x \right)} - 5 \frac{d}{d x} y{\left(x \right)} + \frac{d^{2}}{d x^{2}} y{\left(x \right)} = 0

使用 dsolve 求通解

通解：y{\left(x \right)} = \left(C\_{1} + C\_{2} e^{x}\right) e^{2 x}

\textbf{Answer:}
\[\boxed{y{\left(x \right)} = \left(C_{1} + C_{2} e^{x}\right) e^{2 x}}\]

\problem{6}

一个物体从静止开始自由落体运动，取 $g = 9.8$ m/s²，求下落 3 秒时的速度与下落距离。

\solution

自由落体：v = gt，s = ½gt²（g = 9.8 m/s²）

t = 9.8 s 时：v = 9.8×9.8 = 96.04000000000002 m/s

s = ½×9.8×9.8² = 470.5960000000001 m

\textbf{Answer:}
\[\boxed{v = 96.04000000000002 m/s，s = 470.5960000000001 m}\]
