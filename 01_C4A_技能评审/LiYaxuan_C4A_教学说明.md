# LiYaxuan C4A 教学说明

> 挑战：C4A 技能提交自动评审
> 技能：`c4-skill-evaluator` —— 把"微信群 C4 提交文件夹"变成"自动评审报告"

## 一、这个技能解决什么问题

老师/助教收到一整个文件夹的 C4 技能提交时，需要回答四个问题：

1. 谁交了？谁没交？
2. 五个必备文件（skill说明 / 可执行内容 / demo / 教学说明 / AI日志）齐不齐？
3. 技能本身满足 C4 四条件（可复用 / 可执行 / 可验证 / IO 明确）吗？
4. 每位同学的改进建议是什么？

手动看 40 份提交要一整天；用这个技能，一条命令出完整评审报告（Markdown + Excel + JSON）。

## 二、安装步骤

### 方式 A：安装 .skill 包（推荐给 AI 助手使用）

1. 把 `LiYaxuan_C4A_skill-evaluator.skill` 安装到你的 Agent 环境（Claude Code / 豆包等支持 .skill 的环境）；
2. 对 AI 说："评审 C4 提交：扫描 <文件夹路径>"，AI 会自动调用技能完成评审。

### 方式 B：命令行直接运行（无需 AI 环境）

```bash
# 1. 安装依赖（Python 3.9+）
python -m pip install pyyaml pypdf openpyxl

# 2. 运行评审（把 <提交文件夹> 换成你的路径）
python scripts/c4_skill_evaluator.py <提交文件夹> --output report/ --excel

# 3. 查看输出
#    report/C4_评审报告.md     ← Markdown 评审报告（主交付物）
#    report/C4_评审详表.xlsx   ← Excel 详表（4 个 Sheet）
#    stdout 的 JSON            ← 机器可读结果
```

### 可选增强：国产大模型深度评审

```bash
# Windows PowerShell
$env:DASHSCOPE_API_KEY = "sk-你的通义千问Key"
python scripts/c4_skill_evaluator.py <提交文件夹> --output report/ --llm
```

> 不配置 API 也能完整评审（规则引擎离线可跑）；配置后会在规则评分之外增加 LLM 深度点评。

## 三、输入 / 输出

| | 说明 |
|---|---|
| **输入** | 一个本地文件夹路径（含 C4 提交，命名规范 `姓名_C4_内容描述.扩展名`） |
| **输出** | ① Markdown 评审报告（班级总览/作者详情/排名/改进建议）② Excel 详表（可选）③ JSON |

## 四、评审依据（怎么评分的）

- **完整性**：对照 5 项必备交付物的文件名+内容+扩展名信号，✅ 齐全 / ⚠️ 部分 / ❌ 缺失；
- **质量**：四条件各 2 项以上 check item 满足为 ✅，1 项为 ⚠️，0 项为 ❌；
- **综合分** = 完整性分 × 0.4 + 质量分 × 0.6；
- 评分规则全部在 `references/c4_rubric.yaml`，可自行增删信号（改配置即可，不用改代码）。

## 五、常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 同学命名不规范怎么办？ | 自动回退到文件夹名/文件元数据/文档头部识别；实在认不出来标记为 Unknown，列入"需人工确认"清单 |
| 文件夹里有非 C4 文件？ | 自动过滤，单独列在报告"非 C4 文件"里 |
| 同学交了 v2 又交 v3？ | 自动识别版本号，以最新版本评分，并显示迭代轨迹 |
| 视频/图片 demo 无法分析内容？ | 按文件名与扩展名匹配（mp4/png/jpg 等），不做内容识别 |
| 想调评分权重？ | 修改 `c4_rubric.yaml` 的 `scoring.composite` 与各条件 `weight` |

## 六、边界情况

- 空文件夹：报告"未找到文件"，正常退出；
- 超大文件（>50MB）：跳过内容分析，仅按文件名/类型匹配；
- 编码问题：统一 UTF-8 读取，异常兜底不崩溃；
- LLM API 失败：自动降级为纯规则评审，不影响主流程。

## 七、适用范围

不限于 C4——任何"按规范提交一批技能包/作业并需要打分评语"的场景都能用：改 `c4_rubric.yaml` 的交付物清单和信号即可适配新挑战。
