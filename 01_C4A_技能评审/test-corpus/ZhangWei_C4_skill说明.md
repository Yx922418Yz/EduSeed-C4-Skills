# PPT Generator —— Skill 说明文档

## 解决什么问题
每次做 PPT 都要从空白开始想大纲，本技能把"主题→大纲"变成一句话。

## 使用场景
- 课程汇报、社团活动、比赛路演的大纲生成
- 需要快速从主题发散出结构化页面要点

## 输入 / 输出
输入：主题 + 受众 + 页数（例："AI 入门", "大学生", 12）
输出：Markdown 格式的 PPT 大纲，每页含标题与要点

## 使用步骤
1. 安装 ppt-generator.skill
2. 说"帮我做 PPT 大纲：AI 入门，听众是大学生，12 页"
3. 得到大纲后可直接复制到 PPT 工具

## 真实案例
给校学生会做了 12 页"AI 科普讲座"大纲，10 分钟完成。

## 环境要求
- 纯 prompt + Python 辅助脚本；Python 3.8+，无第三方依赖
- 不依赖特定本地路径，任何电脑可用
