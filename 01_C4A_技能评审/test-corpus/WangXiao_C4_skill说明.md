# 技能X光分析器 —— Skill 说明文档

## 解决什么问题
技能X光分析器解决的是 Elite20 群里"谁交了、交了什么、缺什么"的盘点难题，避免手动整理漏项。

## 使用场景
- 场景1：扫描微信同步文件夹，把所有文档映射到挑战
- 场景2：检查每位同学的提交缺口

## 输入 / 输出
输入：一个本地文件夹路径（微信群同步目录）
输出：按作者×挑战分组的文档清单表 + Excel 文件 + 缺口分析

## 使用步骤
1. 安装 .skill 包到 Claude 环境
2. 说"扫描 <文件夹路径>，映射文档到挑战"
3. 查看 Markdown 清单与 Excel 缺口分析

## 真实案例
用 9 个模拟文件测试，C1-C3 识别正确，缺口分析正确检测到 C2 缺少 paper.pdf。
